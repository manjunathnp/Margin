# Changelog

All notable changes to Margin are documented here.

## [1.0.0] - 2026-09-19

### Added

- Local-first long-document editor and review queue.
- Direct imports for PDF, Markdown, DOCX, HTML, RTF, CSV, JSON, XML, and plain text.
- Rich clipboard import from common document editors and web pages.
- Passage, block, and exact-position insertion reviews.
- Multi-color highlighting with highlight removal.
- Language-selectable, syntax-colored code blocks and inline-code preservation.
- Resizable and collapsible Library and Review panels.
- Individual document deletion and guarded clear-all workflow.
- Markdown review brief plus PDF, Word, HTML, Markdown, and plain-text document exports.
- Light and dark themes with a stable white document canvas.
- Offline branding and PWA metadata using the supplied Margin logo.

### Privacy

- Removed local and external AI connections, model detection, API endpoints, and API-key handling.
- Documents and review data stay in the browser unless explicitly exported.
